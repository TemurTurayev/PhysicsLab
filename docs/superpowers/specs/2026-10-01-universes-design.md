# PhysicsLab — выбор вселенной и мир «Комплекс»: дизайн

**Дата:** 2026-10-01 · **Ветка:** `feat/lab-v1` · **Статус:** на ревью
**Основа:** ресёрч Темура (`half_life_style_open_source_resources.md`) + проверка и расширение (раздел 9).

## 1. Цель

Перед началом обучения ученик выбирает **вселенную**: атмосферу, в которой проходят те же главы.

- **«Классика»** — уже готово: мастерская → полигон → осада замка.
- **«Комплекс»** — новое: подземный исследовательский центр конца 90-х в духе Half-Life.
  Бетон, полосы опасности, гудящие лампы, тестовые камеры, ЭЛТ-терминалы, громкая связь.

Физика, миссии, провалы и прогресс у вселенных **общие**. Меняются окружения, тексты-обёртки,
интерфейс, звук и вид машины. Это не два курса, а два «костюма» одного курса.

## 2. Граница интеллектуальной собственности (жёсткое правило)

Half-Life, логотип «лямбда», Black Mesa, HEV, Combine, персонажи, звуки и текстуры принадлежат Valve.
Мы берём **жанр** (научный комплекс, брутализм, ретро-3D, терминалы) — он не принадлежит никому,
как у Abiotic Factor (оригинальная игра «в духе Half-Life», 2024).

**Нельзя:** названия Half-Life / Black Mesa / Aperture / HEV / Combine / Hazard Course; символ лямбды
и похожие на него знаки; узнаваемые персонажи и монстры; ассеты, звуки и текстуры из игр Valve;
код из Valve SDK (лицензия разрешает его только для модов на движке Valve).

**Можно:** бетон, жёлто-чёрные полосы, оранжевые защитные костюмы как обычная спецодежда,
ЭЛТ-мониторы, громкая связь, научный юмор, низкополигональная графика и пиксельные текстуры
собственного производства.

Все названия, логотип и тексты вселенной — оригинальные. Перед публикацией — проверка по этому списку.

## 3. Мир «Комплекс»

**Название:** НИИ «Сигма-7» — подземный исследовательский комплекс, 1998 год.
Ученик — новый стажёр отдела прикладной механики. Требушет — «Экспериментальная метательная
установка ЭМУ-3»: та же механика (балка, противовес, праща), но стальная рама, бетонные
противовесы в каркасе, тросы.

| Глава | «Классика» | «Комплекс» | Атмосфера |
|---|---|---|---|
| 1 | Мастерская | **Испытательная камера 3** | Бетонный бокс, лампы дневного света, смотровое окно с учёными, полосы опасности, мишени-манекены |
| 2 | Полигон | **Наземный полигон** | Пустыня с плато, ограда, вышка наблюдения, разметка, раскалённое небо |
| 3 | Осада | **Испытание на разрушение** | Ангар с бетонными стенами-мишенями, краном и мигалками |

Провалы становятся **протоколами инцидентов**: «Протокол № 0317-Б. Нарушение режима испытаний
в камере 3». Красный проблесковый маячок, сирена (синтез), голос громкой связи — текстом.
«Журнал инцидентов» превращается в «Архив протоколов». Разборы те же: что, почему, как в жизни.

Манекены остаются манекенами: краш-тест-куклы в оранжевых комбинезонах.

## 4. Визуальный стиль «Комплекса» (наш стек: Three.js в браузере)

Правила из ресёрча, переложенные на наш рендерер:

1. **Текстуры:** процедурные canvas-текстуры 64–256 px с `NearestFilter`: бетон с порами и
   потёками, стальные панели с клёпками, кафель, решётки, полосы опасности, таблички с номерами.
   Никаких фото-текстур по умолчанию. При желании позже — CC0 из Poly Haven и ambientCG,
   уменьшенные до ретро-разрешения.
2. **Свет:** жёсткие контрастные тени от нескольких ламп. Каждая лампа — видимый источник:
   светящаяся панель + `SpotLight`/`RectAreaLight` (правило «мотивированного света» из
   author-game-levels). Тёмные углы, почти нет рассеянного света. Лампы иногда мигают.
3. **Ретро-проход (переключатель «ЭЛТ»):** рендер в пониженном разрешении с nearest-апскейлом,
   лёгкое квантование цвета с упорядоченным дизерингом, слабые строки развёртки.
   Аффинное искажение и дрожание вершин — **выключены** по умолчанию (это PS1, а не GoldSrc,
   и они мешают читать физику). Референс: lferreira457/threejs-psx-shader (MIT) —
   берём идеи, пишем своё.
4. **Палитра:** грязный бетон `#8a877c`, тёмный `#2b2d2e`, сигнальный оранжевый `#ff6a13`,
   полосы `#f2c400`/`#1b1b1b`, люминесцентный белый `#e8f3ef`, фосфорный зелёный `#7dff8a`
   (терминалы), янтарный `#ffb000` (табличка).
5. **Модели:** та же процедурная геометрия, но рубленая: фаски, профиль-швеллер, болты.

## 5. Интерфейс «Комплекса»

Тот же набор панелей, другая «шкура» через CSS-токены (`lab.css` уже на токенах):

- Шрифты: **Share Tech Mono** (цифры, терминал) и **Barlow Condensed** (заголовки), обе OFL.
  Подключаем через `@fontsource`, без внешних запросов.
- Панели — «терминалы»: тёмно-зелёный фон, фосфорное свечение текста, тонкие строки развёртки
  CSS-градиентом (по мотивам Gioni06/terminal.css, MIT), заголовки капсом с номерами разделов.
- Табличка — «телеметрия испытания», карточка провала — «протокол инцидента» с номером и печатью
  «ЗАФИКСИРОВАНО».
- Все эффекты отключаются при `prefers-reduced-motion`; контраст текста не ниже WCAG AA.

## 6. Звук «Комплекса»

Только синтез через Web Audio, без сэмплов: гул ламп (50 Гц + гармоники, тихо), щелчки реле,
гидравлическое шипение при спуске, удар по бетону, сирена инцидента, двухтоновый сигнал громкой
связи перед объявлением. Счётчик Гейгера (интервалы по экспоненциальному закону) — пасхалка
в главе 3. Звук фона — по кнопке, по умолчанию выключен.

## 7. Архитектура

```
src/lab/universe/
  types.ts        Universe { id, name, tagline, envFor(chapter), copy, skin, sfxPack, machineSkin }
  classic.ts      текущие окружения и тексты
  sigma.ts        «Комплекс»: окружения, тексты-обёртки, скин, звук
  copy.ts         applyCopy(mission, universe): заменяет title/brief/goal/hints по id миссии, иначе оригинал
  UniversePicker.tsx  экран выбора перед первой миссией; потом переключатель в шапке карты мира
src/lab/scene/environments/sigma/   testChamber.ts, desertRange.ts, demolitionHall.ts
src/lab/scene/retroPass.ts          низкое разрешение + квантование + строки (переключатель)
src/lab/scene/textures/industrial.ts процедурные canvas-текстуры
src/lab/audio/packs/sigma.ts
```

- Выбор хранится в `labProgress` (`universe: 'classic' | 'sigma'`). Прогресс и журнал общие.
- `LabPage` берёт окружение через `universe.envFor(mission.chapter)`, а тексты — через `applyCopy`.
- Физика и `levels/` не меняются. Тексты вселенной — оверлей по id миссии, поэтому новая глава
  в «Классике» сразу работает и в «Комплексе», пока для неё нет своего оверлея.

## 8. Объём и фазы

- **Фаза A (этот план):** инфраструктура вселенных, экран выбора, скин интерфейса «терминал»,
  ретро-проход, звуковой пакет, **Испытательная камера 3** (глава 1) и тексты главы 1.
- **Фаза B:** Наземный полигон (глава 2) и его тексты.
- **Фаза C:** Испытание на разрушение (глава 3), стальная ЭМУ-3 с бетонными противовесами.

Пока у главы нет окружения «Комплекса», карта мира показывает её как «доступ закрыт — сектор
на реконструкции» и предлагает пройти её в «Классике». Миры не смешиваются в одной сцене.

## 9. Ресёрч: что пригодилось, что нет

| Источник | Вердикт |
|---|---|
| Xash3D, HL1 SDK, Source SDK | Не используем: это движки на C/C++, SDK под лицензией Valve только для модов |
| TrenchBroom (GPL-3) + загрузчик `.map` для three.js | Не в фазе A: процедурная раскладка на TS проще. Вернёмся, если понадобятся сложные уровни |
| Qodot | Заархивирован, преемник func_godot — для Godot, нам не нужен |
| `gregmar/terminal.css`, `mwh/crt-mpv` | Не существуют. Настоящий — Gioni06/terminal.css (MIT): берём идеи для CSS-скина |
| PSX-шейдеры (Unity/Godot) | Идеи. Для three.js — lferreira457/threejs-psx-shader (MIT) |
| Share Tech Mono, Oswald, Barlow Condensed, Roboto Condensed | Все под открытыми лицензиями. Берём Share Tech Mono + Barlow Condensed |
| Poly Haven, ambientCG | CC0 — можно, но по умолчанию процедурные текстуры |
| Freesound | Лицензии разные (CC0, CC-BY, CC-BY-NC); в фазе A не берём, синтезируем сами |
| Abiotic Factor (2024) | Главный референс того, как сделать «в духе HL» с оригинальной вселенной |
| Учебный курс HL1 (уровень-обучение) | Принцип «станции и пронумерованные шаги, светящиеся номера на стенах» — берём для карты глав |

## 10. Проверка

- Unit: `applyCopy` (оверлей и откат к оригиналу), выбор окружения по главе, сохранение выбора.
- Скриншоты Испытательной камеры на 1440 px и 375 px, оценка по рубрике (небо/свет, материалы,
  композиция, атмосфера, читаемость интерфейса) до 8+.
- Проверка списка из раздела 2 по всем строкам вселенной (`rg` по запрещённым словам в CI-тесте).
- Ретро-проход: ≥ 50 к/с на ноутбуке, выключается одной кнопкой.
